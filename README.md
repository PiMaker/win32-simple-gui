## Win32 Simple GUI

The most lightweight embeddable GUI framework for Windows.

It's literally just some managed bindings around Win32 APIs.

AOT safe for where WinForms and WPF can't go, directly vendorable for single-file apps, and in the kilobyte range compared to big UI frameworks like Avalonia.

Look, it won't be pretty, but it's the Laziest™ way to add a GUI to your windows app.
